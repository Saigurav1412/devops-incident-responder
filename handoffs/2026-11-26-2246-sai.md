## Goal of this session
Build the LLM-backed Reasoner and the prompts, provider-independent, so only a thin provider
adapter waits on the LLM decision. Prompts are built from the executor's policy summaries on its
Agent Card (Om's PR #12).

- `src/diagnoser/llm.py` — new: `ChatModel` protocol (`complete(messages, schema, schema_name,
  max_output_tokens) -> ChatResult(text, input_tokens, output_tokens)`), `ChatMessage`,
  `ChatModelError`
- `src/diagnoser/reasoner.py` — new: `LLMReasoner` (plan / next_command / assess / propose),
  `render_incident()` (nonce-fenced JSON data blocks, output tails, last 12 observations with
  output, no approval token), strict answer models (`PlanAnswer`, `CommandAnswer`, `AssessAnswer`,

  defaults, token accounting incl. failed attempts, policy cached on success only, `prompt_refs`

  counted; new `route_after_propose` (None → escalate)
